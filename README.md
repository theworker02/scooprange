# scooprange

Scoop identifiers and range tokens for idempotent workflows.

**Site:** https://theworker02.github.io/scooprange/

## Install / run

```bash
git clone https://github.com/theworker02/scooprange.git
cd scooprange
node src/cli.js
node --test
```
